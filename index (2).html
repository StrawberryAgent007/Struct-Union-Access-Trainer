  • Look at the left-hand name first. A struct variable takes .. A pointer takes ->. Most mistakes are this one swap.
    • 

  • ptr->x is shorthand for (*ptr).x. The parentheses matter: *ptr.x means *(ptr.x), which fails because ptr has no members.
    • 

  • Nested structs: only the first hop depends on what you hold. ptr->pos.x uses -> once, then ., because pos is a struct, not a pointer.
    • 

  • Literals: 'A' is one char; "A" is a string. 4.5f is a float; plain 4.5 is a double. This trainer accepts both for floats.
    • 

  • Statements end with ;, expressions such as ptr->voltage or &s.id do not need one here.
    • 

  • Unions: the size is the largest member, and only the member you wrote last holds a meaningful value. Real code often pairs a union with a tag field that records which member is active.
    • 

  • Precedence: ., -> and [ ] bind tighter than & and *, so &ptr->id means &(ptr->id).
    • 

  • You can’t assign whole arrays or strings with =. Use s.name[0] = 'Z'; or strcpy.
